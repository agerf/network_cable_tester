Kabelprüfung

Beide Enden einstecken, dann testen.

Der Slave misst am gegenüberliegenden Ende. Der Test dauert nur wenige Sekunden.

Wichtig: Beide Tester brauchen eine gemeinsame Masse (z. B. beide USB-Kabel am selben Rechner oder Hub).

Wackeltest: wiederholt den Test; dabei am Stecker/Kabel wackeln. Instabile Adern werden pro Ader gemeldet.

Wackeltest Intermittenz

Während des Laufs am Stecker wackeln. „stabil“ = in allen Läufen dieselbe Verbindung, ohne Unterbrechung oder Kurzschluss.

Verdrahtung

Durchgezogen = gemessene Verbindung · gestrichelt = offen · gelb = an einem Kurzschluss beteiligt.

Messmatrix

Messmatrix: Zeilen sind getriebene Adern an Node A, Spalten sind gelesene HIGH-Pegel an Node B.

Zeile: getriebene Ader an A · Spalte: HIGH gelesen an B.

Diagnose

Längen pro Ader · experimentell

Median über mehrere Kapazitätsmessungen, per Ader kalibrierbar (Konsole: len cal <meter>); typische Abweichung ±20–30 %. Bei offenen Adern wird die Bruchdistanz vom Master geschätzt; kurzgeschlossene Adern haben keinen Längenwert.
